# 小红书视频下载器 · 纯网页版

单文件网页工具：粘贴小红书分享链接，提取视频直链，支持页面内预览和下载。

**在线使用**：部署后地址为 `https://<你的用户名>.github.io/xhs-video-downloader/`
（手机浏览器打开 → 菜单 →「添加到主屏幕」，即可像 App 一样使用。）

## 使用说明

- 粘贴 App 里「复制链接」得到的分享链接（短链 / 完整链接 / 整段分享文案均可），
  链接中的 `xsec_token` 参数不要删
- 解析这一步通过 CORS 代理转发：默认使用公共代理（免费但不稳定，失败请稍后重试）；
  **推荐部署自己的 Cloudflare Worker 代理**（见 [worker.js](worker.js) 文件头部注释，
  约 3 分钟），然后在页面「⚙️ 设置」里填入你的 Worker 地址，稳定且链接不经过第三方
- 需要登录才能看的笔记无法解析（代理带不了登录态）
- 页面内预览如被 CDN 拦截，点「打开/下载视频」用浏览器播放，播放器右下角即可保存

## 文件

- `index.html` — 全部功能都在这一个文件里，也可以直接下载后本地打开
- `worker.js` — 可选的自建代理（Cloudflare Worker，免费额度足够个人使用）
